# Laman rasmi SK Combined AI

## Fail
- `index.html` — laman utama
- `privacy.html` — Dasar Privasi
- `terms.html` — Terma Penggunaan
- `support.html` — Bantuan dan Sokongan

## Terbitkan dengan GitHub Pages
1. Pastikan semua fail ini berada di root repositori `skcombinedai.github.io`.
2. Buka **Settings → Pages** dalam repositori.
3. Di bahagian **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/(root)`, kemudian tekan **Save**.
5. Tunggu sehingga GitHub Pages selesai diterbitkan. Semak URL sebenar di bahagian Pages.

## Semakan sebelum digunakan untuk penerbitan plugin
Semak semua kandungan, terutama kenyataan privasi dan alamat e-mel. Pautan halaman hanya boleh dimasukkan ke metadata plugin selepas laman diterbitkan dan setiap URL diuji boleh dibuka tanpa log masuk.
